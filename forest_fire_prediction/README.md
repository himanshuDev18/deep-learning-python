# Forest Fire Detection using CNN

A Convolutional Neural Network (CNN) model for classifying forest fire images into two categories:
- Wildfire
- No Wildfire

## Features

- Image classification using CNN
- Data preprocessing with ImageDataGenerator
- Model training and evaluation
- Accuracy visualization
- Prediction on custom images
- Saved trained model (.h5)

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Dataset

Wildfire Prediction Dataset (Kaggle)

## Results

- Test Accuracy: ~97%

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Open the notebook

```
notebooks/forest_fire_cnn.ipynb
```

3. Train the model or load the saved model.
